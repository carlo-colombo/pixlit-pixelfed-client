# Pixlit

Pixlit is a modern Android image uploader for [Pixelfed](https://pixelfed.org/), the federated image sharing platform. This is a personal project built for one user (carlo-colombo) with a focus on a streamlined upload experience.

## Tech Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Networking:** Retrofit & OkHttp
- **Image Loading:** Coil
- **Concurrency:** Kotlin Coroutines & Flow
- **Architecture:** MVVM / MVI (Follows official Android architecture guidelines)

## Getting Started

### Prerequisites
- Android Studio Koala or newer
- JDK 17
- Android SDK 34

### Building
1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/pixlit.git
   ```
2. Open the project in Android Studio.
3. Sync Gradle and run the `:app` module.
